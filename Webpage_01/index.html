Idea Title

QueueSetu — a smart farmer procurement & queue management platform.

Every booking moves through the same four stages. Step through them below to see what happens at each one.

How it addresses the problem

  • Removes long physical waiting — farmers arrive close to their turn
  • A live slot calendar ends uncertainty about procurement schedules
  • Real-time token tracking gives full status transparency

What makes it different

  • SMS-first — works for feature-phone farmers, not just smartphone users
  • Dynamic, ML-based wait-time prediction instead of static estimates
  • Centre load-balancing suggests less-busy nearby centres
  • Government-ready secure architecture (JWT + Spring Security), built to scale

Technical Approach

Five layers, one continuous pipeline.

Select a layer to see the technology behind it.

Methodology & process

  1. Farmer books a slot → a token is generated → the Queue Engine tracks position
  2. WebSocket broadcasts live "now serving" updates to every connected user
  3. A rule-based wait-time estimate runs now; an ML model trained on logs comes later
  4. An SMS alert triggers as the farmer nears their turn; load-balancing suggests shorter-wait centres
  5. Dockerized backend with CI/CD via GitHub Actions to Render; frontend deployed on Vercel
